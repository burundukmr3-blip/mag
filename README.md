# Своя игра

Веб-приложение для проведения «Своей игры» на общем экране: ноутбук, подключённый к проектору или телевизору. Один ведущий, от 2 до 4 игроков. Приложение показывает табло, вопросы с картинками, видео и аудио, считает очки и проводит финал со ставками. Весь контент редактируется в самом приложении, программист для этого не нужен.

Работает без интернета и без регистрации. Игры, картинки и видео хранятся только в браузере на устройстве ведущего.

---

## Как смержить

Код приложения лежит в ветке **`feature/svoya-igra`**, в ветке `main` пока только описание. Чтобы перенести код в `main`, выберите один из вариантов.

### Вариант 1. Через сайт GitHub

1. Откройте страницу сравнения веток:
   **https://github.com/burundukmr3-blip/mag/compare/main...feature/svoya-igra**
2. Нажмите **Create pull request**, затем ещё раз **Create pull request**.
3. На странице pull request нажмите **Merge pull request**, затем **Confirm merge**.
4. Ветку `feature/svoya-igra` после этого можно удалить кнопкой **Delete branch**.

### Вариант 2. Из командной строки

```bash
git clone https://github.com/burundukmr3-blip/mag.git
cd mag
git checkout main
git merge origin/feature/svoya-igra
git push origin main
```

Ветка начата от `main`, поэтому слияние пройдёт без конфликтов.

## Как запустить

Нужен **Node.js 20 или новее** ([nodejs.org](https://nodejs.org), версия LTS) и любой современный браузер: Chrome, Edge, Firefox или Safari.

```bash
git clone https://github.com/burundukmr3-blip/mag.git
cd mag
npm install
```

### Для игры

```bash
npm start
```

Команда собирает приложение и открывает его в браузере по адресу **http://localhost:4173**. То же самое по шагам: `npm run build`, затем `npm run preview`.

После первого открытия приложение работает и без интернета. Если сервер уже остановлен, страница **http://localhost:4173** всё равно откроется из кэша браузера.

### Для разработки

```bash
npm run dev
```

Приложение откроется по адресу **http://localhost:5173**. Изменения в коде видны сразу, без перезагрузки.

### Важно про адрес

Браузер хранит данные отдельно для каждого адреса. Игры, созданные на `localhost:5173`, не видны на `localhost:4173`, и наоборот. Готовьте игру и проводите её по одному и тому же адресу. Чтобы перенести игру на другой адрес, другой браузер или другое устройство, используйте кнопки **Экспорт** и **Импорт из файла**.

### Без Node.js на устройстве ведущего

Соберите приложение на любом компьютере (`npm run build`) и выложите папку `dist` на любой статический хостинг: GitHub Pages, Netlify, свой сервер. Достаточно один раз открыть сайт с интернетом, дальше он работает офлайн. Открыть `dist/index.html` двойным щелчком нельзя: браузеры не запускают такие приложения из файла.

## Как провести игру

1. На главном экране нажмите **Добавить пример «Осень и Хэллоуин»** или **Новая игра**.
2. Нажмите **▶ Играть**, введите имена игроков, выберите цвета и, если хотите, аватары. Список игроков можно сохранить для следующих игр.
3. Нажмите **▶ Начать игру**, затем **F** или кнопку **⛶**, чтобы включить полный экран.
4. Нажмите на карточку на табло. Когда игрок отвечает голосом, выберите его внизу экрана (щелчком или клавишами **1–4**) и нажмите **Верно** или **Неверно**.
   - После неверного ответа вопрос остаётся открытым для других игроков.
   - **Показать ответ** открывает ответ, картинку к ответу и комментарий для ведущего.
   - **Никто не ответил** закрывает вопрос без изменения очков.
   - Право выбора следующего вопроса переходит к тому, кто ответил верно.
5. Ошиблись? Нажмите **↶ Отменить** (или **Ctrl+Z**). В **Журнале** можно отменить любое начисление очков. Чтобы вручную поправить счёт, нажмите на игрока.
6. Когда раунд сыгран, появится кнопка следующего раунда, после последнего раунда — финала. Переключить раунд можно в любой момент через **☰ Меню**.
7. В финале игроки по очереди убирают темы, затем ведущий вводит ставки, показывает вопрос и отмечает ответы. После этого открывается итоговый экран, а результат сохраняется в **Историю игр**.

Игра сохраняется после каждого действия. Если закрыть вкладку, на главном экране появится кнопка **▶ Продолжить**.

### Особые карточки

- **Кот в мешке** — ведущий объявляет тему и стоимость и отдаёт вопрос другому игроку. Отвечает только этот игрок.
- **Вопрос со ставкой** — игроки торгуются вслух, ведущий выбирает победителя торга и вводит ставку. Есть кнопка «Ва-банк».

### Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| Стрелки, Enter | выбор карточки на табло |
| Пробел | показать или скрыть ответ |
| 1–4 | выбрать отвечающего игрока |
| Enter или + | верно |
| − или Backspace | неверно |
| N | никто не ответил |
| Esc | назад к табло |
| T | пауза таймера |
| Ctrl+Z или U | отменить последнее действие |
| F | полноэкранный режим |

## Редактор игры

- **Раунды.** По умолчанию три раунда по 6 тем и 5 вопросов, номиналы ×1, ×2, ×3 (100–500, 200–1000, 300–1500). Номиналы, число тем и вопросов меняются в редакторе.
- **Темы.** Создаются, переименовываются, удаляются. Порядок меняется перетаскиванием за значок ⠿.
- **Вопросы.** Текст, ответ, номинал, комментарий для ведущего, тип карточки. Вопрос можно перенести в другую тему или раунд: перетащите его на другую тему или выберите тему в списке.
- **Медиафайлы.** Картинка к вопросу и отдельно к ответу (JPG, PNG, WebP; файлом, перетаскиванием или вставкой из буфера обмена). Видео (MP4, WebM или ссылка на YouTube либо на MP4) с настройкой начала и конца фрагмента, автозапуска и звука. Аудио (MP3, OGG, WAV, M4A) для вопросов «угадай мелодию». О видео больше 100 МБ приложение предупреждает, порог меняется в настройках.
- **Предпросмотр** показывает вопрос так, как его увидят игроки.
- **Все вопросы** — вся игра одним списком с поиском.
- **Проверить** находит пустые вопросы, вопросы без ответа, повторяющиеся номиналы, пропавшие и слишком большие файлы.
- **Медиатека** собирает все загруженные файлы в одном месте: размер, где используется, повторное использование, удаление неиспользуемых.

### Импорт вопросов из таблицы

Кнопка **Импорт таблицы** в редакторе принимает CSV и Excel (`.xlsx`, первый лист). Ячейки можно и просто скопировать из Excel или Google Таблиц и вставить в окно импорта.

| Раунд | Тема | Номинал | Вопрос | Ответ | Комментарий |
| --- | --- | --- | --- | --- | --- |
| 1 | Осенние месяцы | 100 | Какой месяц открывает календарную осень? | Сентябрь | |

Колонки «Раунд» и «Комментарий» необязательны. Образец CSV можно скачать в окне импорта.

### Перенос игры на другое устройство

**Экспорт** на главном экране сохраняет игру в один файл `.svoya` вместе со всеми картинками, видео и аудио. На другом устройстве нажмите **Импорт из файла** и выберите этот файл.

## Где хранятся данные

Всё лежит в IndexedDB браузера на этом устройстве. На сторонние серверы ничего не отправляется. Исключение — видео по ссылке на YouTube: для него нужен интернет во время игры, о чём предупреждает проверка игры.

Если очистить данные сайта в браузере, игры удалятся. Для резервной копии делайте экспорт важных игр.

## Для разработчиков

Стек: React 18, TypeScript, Vite. Из зависимостей во время работы только `fflate` для чтения `.xlsx`.

```bash
npm run typecheck   # проверка типов
npm test            # тесты логики игры, экспорта, импорта таблиц и проверки игры (нужен Node.js 22.6+)
npm run build       # сборка в папку dist
```

```
src/
  lib/            логика без интерфейса
    session.ts    ход игры: вопросы, очки, кот в мешке, ставки, финал, журнал
    store.ts      состояние приложения, автосохранение, стек отмены
    model.ts      структура игры, создание и изменение раундов, тем и вопросов
    exchange.ts   формат файла .svoya для экспорта и импорта
    tableImport.ts, xlsx.ts   импорт вопросов из CSV и Excel
    validate.ts   проверка игры перед запуском
    sample.ts     пример «Осень и Хэллоуин»
    db.ts, media.ts           IndexedDB и медиафайлы
  screens/        экраны: главная, редактор, подготовка, игра, медиатека, история, настройки
  components/     общие элементы интерфейса
  sw.js           сервис-воркер для работы без интернета
```

### Что из требований сделано

Реализованы все требования с приоритетом «обязательно» и «желательно» из документа требований (И1–И15, Р1–Р17, С1–С11, Н1–Н8). Не сделана только адаптация под планшет (Н9, приоритет «потом»).

Вопросы примера «Осень и Хэллоуин» составлены для этого шаблона. Их можно заменить своими в редакторе или загрузить из таблицы.
